# Lange International Trade Services — Corporate Website

GitHub Pages-ready corporate website for Lange International Trade Services.

## Included

- `index.html` — main corporate website
- `style.css` — responsive corporate design system
- `script.js` — mobile navigation
- `images/logo.png` — original Lange logo
- `images/favicon.png` — browser icon
- `assets/Lange_International_Trade_Services_Company_Profile_2026.pdf` — downloadable company profile

## GitHub repository structure

```text
index.html
style.css
script.js
README.md
images/
  logo.png
  favicon.png
assets/
  Lange_International_Trade_Services_Company_Profile_2026.pdf
```

## Updating the live GitHub Pages site

Upload all files and folders to the root of the existing repository and commit the changes.

GitHub Pages should remain configured as:

- Source: Deploy from a branch
- Branch: main
- Folder: /root

The live site will automatically redeploy after the commit.

## Custom domain

When a domain is purchased, add it in GitHub:

Settings → Pages → Custom domain

Do not add a `CNAME` file until the final domain has been chosen.
